# Data

## Current state: synthetic only

This build has **no real market data**. Yahoo Finance and Stooq both return
HTTP 403 from the build environment; the network allowlist covers PyPI, GitHub,
npm and crates only.

`data/processed/panel.parquet` is generated by `statarb.data.synthetic` and
contains 60 symbols × 2,515 sessions = 150,900 rows spanning 2016-01-04 to
2025-12-31. `data/processed/ground_truth.json` labels 30 cointegrated pairs,
12 correlated-only decoys and 6 regime-break pairs.

Regenerate with:

```bash
python -m statarb.cli synth
```

## Getting real data

```bash
pip install '.[market]'
# set data.source: yahoo in config/default.yaml
python -m statarb.cli download
python -m statarb.cli validate
```

The `YahooSource` adapter is implemented but **was never executed** — there was
no network path to test it. Treat its first run as unverified code.

Once real data is loaded, every metric currently marked `NOT YET MEASURED` in
`reports/resume_metrics.md` can be filled in by running `make all`.

## What to check before trusting real data

Run `python -m statarb.cli validate` and read every WARNING, not just the
FAILs. In particular:

- **Survivorship.** If your ticker list came from a current index membership,
  it has already discarded every company that failed. This is the single
  largest bias risk in the project and no code here can detect it.
- **Adjusted close restatements.** Vendors silently restate history after
  corporate actions, so a backtest run today may not reproduce next month.
- **Stale runs.** `longest_stale_run_days` catches frozen feeds that the
  run-count check misses.
